Code Workspace · Live

An editor that remembers your files.

Open a project and the real tree appears. Edit, rename, create and delete; every save writes through to IndexedDB. Reopening the project restores the saved contents, not a demo snapshot.

Open the app Workspace guide

Real file operations

Create files and folders, rename with draft preservation, and delete with confirmation. Duplicate names and unsafe paths are rejected before a write.

Dirty state you can trust

Tabs use Monaco's alternative version id, so the dot means the buffer differs from the stored copy. Closing a dirty tab offers Save & close, Discard or Cancel.

Fast navigation

Ctrl/⌘ P quick open, project-wide content search with capped results, tab cycling, save all and find & replace.

Diagnostics from Monaco

The Problems panel reads real markers from open buffers. It discloses that there is no project-wide module resolution yet.

Linked folders are a fallback

If a folder was imported with the File System Access API, its real bytes are read only when no saved copy exists. Permission prompts are shown.

Run without leaving

The Run tab reads the live draft and calls the local execution service. It never claims a run happened without a response.

Storage model

Schema v4 keeps project records, tree entries and file contents separately. Contents are loaded on demand, so a large project does not materialize every file at once. A stored copy is authoritative after the first save; the folder handle is only a read fallback.

Not cloud sync. The registry belongs to this browser profile. Clearing site data removes it. Export and archive are scheduled, not implemented.
