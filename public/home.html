A laboratory for software that thinks with you.

CodePilot Lab combines a real Monaco workspace, a provider-independent AI copilot, local code execution, a Python variable tracer, private practice grading and a review-first converter. It runs in your browser, stores projects in this device's IndexedDB, and never invents activity you did not create.

What it is

An instrument, not a dashboard.

Most learning tools hide the machine. CodePilot Lab exposes it: real compiler output, real trace events, real diffs and real storage facts. When something is unavailable, the screen says so and prints the command that starts it.

Code Workspace

A persisted file tree, tabs, dirty buffers, quick open, project search and Monaco language services — with saves written to IndexedDB, not to a pretend cloud.

Live · /workspace

AI Copilot

Native Ollama or any OpenAI-compatible endpoint. You choose the context, preview the exact bundle, and review complete-file proposals as diffs before anything changes.

Live · /copilot

Execution & tracing

A loopback Node sidecar compiles and runs Python, JavaScript, TypeScript, C, C++, Java. Python tracing comes from real sys.settrace events.

Live · /lab

Practice Arena

Thirteen original problems, visible cases you can run, and hidden suites that are graded server-side. Expected hidden outputs never reach the browser.

Live · /practice

Code Converter

Nine languages, streamed provider output, a real LCS diff, accept/reject, download, save-as-new and explicit replace. Conversion quality is never overstated.

Live · /convert

Project Vault & Atlas

Archive, export and dependency graphs are scheduled, not simulated. The routes are labelled “Scheduled” and list exactly what is missing.

Scheduled · /vault · /atlas

Who it is for

Learners who want to see the machinery.

It is designed for developers building fluency across languages, students who need to understand why a loop behaves a certain way, and anyone who wants AI help without surrendering their code or their judgement.

See execution, not just output

Step through Python statements, inspect locals, walk the call stack and scrub a real event timeline.

Keep the source of truth local

Projects, drafts, conversions and practice progress live in your browser profile. Linked folders are read-only fallbacks and are disclosed as such.

Use the model you already run

Ollama, LM Studio, llama.cpp or a remote OpenAI-compatible provider. No key ships in the bundle; persistence is opt-in.

Start in three minutes

Create one file. Run it. Trace it.

npm install
npm run dev      # http://localhost:5173
npm run exec     # loopback execution service on 127.0.0.1:5310

The editor, conversion review and practice browsing work without the sidecar. Running, tracing and submission print the exact start command instead of pretending.
