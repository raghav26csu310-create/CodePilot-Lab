Features, with the missing parts named.

CodePilot Lab is built in deliberate phases. A module is listed as live only when its interactions, persistence and failure states work in this repository. Scheduled modules say exactly what is not built yet.

Command Center Live

Time-of-day greeting, real project registry, create/import dialogs, quick actions, system status and the lazy Lattice-01 scene. Empty states are empty — no sample projects are seeded.

/

Code Workspace Live

Persisted tree, create/rename/delete, tabs, dirty protection, save and save-all, quick open, project search, Monaco diagnostics and a workspace Run tab.

/workspace/:projectId

AI Copilot Live

Seven modes, two provider adapters, explicit context toggles, exact bundle preview, streamed responses, stop, proposal parsing and reviewable diffs. No provider is configured by default.

/copilot · /settings

Execution Lab Live

Real compile/run through a loopback Node service, six advertised runtimes plus Go, stdin, measured duration, output caps, Stop and honest unsupported states.

/lab · npm run exec

Variable Tracer Live · Python only

Real sys.settrace events, step forward/back, play/pause, timeline scrubber, locals, call stack and branch observations. Other languages are marked unsupported rather than simulated.

/lab → Trace

Practice Arena Live

Thirteen original problems, six languages, persisted drafts and notes, hints, visible-case runs, private-suite submissions and hidden-test protection.

/practice

Code Converter Live

Nine languages, project/editor/paste sources, streamed conversion, LCS diff, accept/reject, download, save-as-new, confirmed replace, history and validation runs.

/convert

Project Vault Scheduled

Archive moves, export/import and quota handling are not implemented. The route says so and lists the planned work; no fake archive controls are shown.

/vault

Project Atlas Scheduled

Import graphs need a real module analysis layer that does not exist yet. The route is a labelled placeholder rather than a decorative fake graph.

/atlas

Activity & Diagnostics Scheduled

A persistent event log is not built. Diagnostics that already exist live inside the workspace panel and System Status, fed by real Monaco and browser APIs.

/activity

Settings Live

Provider preset, base URL, model, optional key persistence, connection test and context budget. Saving clears the “verified” claim until a real request succeeds.

/settings

Feedback Live

Writes to IndexedDB first, then optionally POSTs to a configured endpoint. The result panel states which delivery actually happened.

/feedback

Editor-only languages

HTML, CSS and JSON open with syntax highlighting, formatting and diagnostics, but they have no runtime in the execution service. The UI labels them editor-only instead of offering a Run button that cannot work.

What “local-first” means here

Projects, contents, conversions, practice progress and feedback are stored in this origin's IndexedDB. There is no account and no application backend. The only network calls are ones you configure: an AI provider, the optional feedback endpoint, and the loopback execution service.
