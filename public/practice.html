Practice Arena · Live

Problems graded by tests, not vibes.

Thirteen original problems across arrays, strings, hashing, sorting, binary search, two pointers, windows, linked lists, stacks, queues, recursion, backtracking, trees, graphs, DP, greedy, bits and math. Visible cases run locally; submissions use a private suite.

Browse problems How grading works

Visible cases

Run the published cases without consuming a submission. Output and stderr are shown exactly as produced.

Private suites

Hidden inputs and expected outputs live only in server/problems.mjs. The browser never bundles them.

Bounded feedback

/grade returns case indices, hidden flags, statuses and bounded visible stderr — never hidden inputs, expected outputs or full hidden output.

Six languages

Python, JavaScript, TypeScript, C, C++ and Java where the problem supports it. Drafts are stored per language.

Progress that persists

Attempts, solved state, bookmarks, notes and submission history are stored in IndexedDB with real timestamps.

Hints before answers

Progressive hints are open; explanations and full solutions are gated so the problem is not spoiled by default.

Submission, plainly

Submit requires the local execution service. If it is not running, the page shows the start command and keeps your work. A verdict is only recorded after the service answers.

Local grading only. Hidden tests protect against overfitting, not against determined extraction. They are not cryptographic secrets; they live on the operator's machine.
