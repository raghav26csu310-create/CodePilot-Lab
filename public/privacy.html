Privacy · Last updated 10 November 2026

Privacy policy.

CodePilot Lab is local-first. It has no account system and no application backend of its own. Most data never leaves your browser; the exceptions are listed explicitly below.

Data stored on your device

Through IndexedDB and localStorage for this site's origin, the app may store:

  • Project records: name, description, language, source type, timestamps, file counts, manifest, exclusions and an optional folder handle.
  • File tree entries and saved file contents you create, import or edit.
  • Conversion history, practice drafts, notes, bookmarks, progress and submissions.
  • AI provider settings: preset, base URL, model and non-secret preferences. An API key only if you opt into “remember in this browser”.
  • Feedback submissions and their delivery status.
  • Interface preferences such as the sidebar state and welcome-card dismissal.

This data stays in your browser profile for this origin. It is not synced by CodePilot Lab. Clearing site data or using a private window removes or isolates it.

Data that can leave your device

  • AI provider requests. When you press Send in the copilot or converter, the exact context shown in the context panel is sent to the endpoint you configured. That provider's privacy terms apply. CodePilot Lab does not proxy or retain it.
  • Feedback. If the deployment configured VITE_FEEDBACK_ENDPOINT, the feedback payload is POSTed there without cookies or credentials. If not, it stays local.
  • Local execution service. Code you run or trace is sent to the loopback service at 127.0.0.1 on the same machine. It is not sent to a remote server by CodePilot Lab.

Analytics

No analytics provider is configured in this release. The app does not set advertising cookies, build cross-site profiles or transmit telemetry by default. If an operator adds a privacy-conscious analytics endpoint, this policy and the deployment documentation must be updated before launch.

Logs and error reporting

The browser console may contain local error details. The loopback service logs request failures to its own terminal, including unexpected errors, but does not write a remote log. Do not include secrets in feedback.

Your controls

  • Delete individual projects from the project picker; deletion cascades through stored entries and contents.
  • Clear conversations and conversions in the app, or clear all site data from your browser settings.
  • Forget a remembered API key in Settings.
  • Use the browser's storage controls to inspect or remove IndexedDB data for this origin.

Children and sensitive data

The beta is aimed at developers and learners. Do not submit sensitive personal data, regulated data, credentials or third-party confidential code. There is no age-gated account system because there are no accounts.

Changes and contact

Material changes will be reflected in this page and the repository. For privacy questions or removal requests relating to a configured feedback endpoint, use the feedback page and include only the minimum information needed.
