The form is part of the application, not this static page. It writes to this browser's IndexedDB first and optionally POSTs to the deployment's configured feedback endpoint.

Open the feedback form How delivery works

What happens to a submission

  1. A record is written to IndexedDB, including category, rating, feature, message, optional contact, page, app version and time.
  2. If VITE_FEEDBACK_ENDPOINT is configured, the same JSON is POSTed with no credentials or cookies.
  3. The success panel reports one of three honest outcomes: stored locally only, delivered to the endpoint, or stored locally with a failed delivery and its HTTP status.
Privacy. Do not paste API keys, passwords, private source code or personal data you do not want stored. Contact details are optional. See the privacy policy.

No endpoint configured?

A local-only submission is still real: it is stored in your browser profile and can be inspected or cleared with site data. It has not reached the maintainer automatically. The form says so plainly instead of showing a fake “message sent” state.
